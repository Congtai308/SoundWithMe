# Deploy SoundWithMe (Render + MongoDB Atlas, free plans)

One Render web service runs the web app and the API together (the web server
proxies `/api/v1` and `/socket.io` to the API inside the container), so the
site, its cookies, sockets and karaoke stay on one origin. Redis is Render
Key Value; MongoDB is MongoDB Atlas. All three have free plans.

| Piece | Where | Defined in |
| --- | --- | --- |
| Web + API | Render web service `soundwithme` (Docker) | `render.yaml`, `infrastructure/docker/app.Dockerfile` |
| Redis | Render Key Value `soundwithme-redis` | `render.yaml` |
| MongoDB | MongoDB Atlas, free M0 cluster | set by hand (step 1) |

Free plan limits:
- The service **sleeps after 15 minutes without visitors**; the next visit waits about a minute.
- Free Key Value keeps data in memory only: a restart forgets live playback positions,
  pending sign-up links and rate-limit counters. Accounts, rooms, messages and logins
  are in MongoDB and survive.
- The paid Starter plan ($7/month) removes the sleep.

## 1. MongoDB Atlas

1. Sign up at <https://www.mongodb.com/cloud/atlas/register> and create a **free M0** cluster
   (provider AWS, region **Singapore** `ap-southeast-1`).
2. **Database Access** → add a user with a generated password (role: read and write to any database).
3. **Network Access** → add `0.0.0.0/0` (Render's free plan has no fixed outgoing IP).
4. **Connect → Drivers** → copy the connection string and add the database name
   `soundwithme` before the `?`, e.g.
   `mongodb+srv://USER:PASSWORD@cluster0.xxxxx.mongodb.net/soundwithme?retryWrites=true&w=majority`

## 1b. Brevo (account mail)

Sign-up links and password resets are sent through Brevo's HTTPS API (free: 300 mails a day).

1. Sign up at <https://www.brevo.com>.
2. **Senders, domains & dedicated IPs → Senders** → add and verify the address mail comes from
   (your Gmail address works).
3. **SMTP & API → API Keys** → **Generate a new API key**. It starts with `xkeysib-`
   (the `xsmtpsib-` keys on the SMTP tab are for SMTP and don't work here).
4. `MAIL_FROM` is that sender, e.g. `SoundWithMe <you@gmail.com>`.

Leave both empty to skip mail: the app runs, and sign-up links only appear in the service's logs.

## 2. Render

1. Sign in at <https://render.com> with GitHub and allow access to the `SoundWithMe` repository.
2. **New → Blueprint** → pick the repository. Render reads `render.yaml` and proposes the
   web service and the Key Value instance.
3. Fill in the secrets it asks for (same values as `apps/api/.env`):
   - `MONGODB_URI`: the Atlas string from step 1
   - `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`
   - `BREVO_API_KEY`, `MAIL_FROM`: account mail (step 1b). Render's free plan blocks SMTP,
     so Gmail SMTP can't be used there.
   - `YOUTUBE_API_KEY` (optional: search needs it; pasted links work without)
   JWT secrets are generated by Render. The public address (`WEB_APP_URL`) and the Google
   callback are taken from Render's own URL automatically.
4. **Apply.** The first build takes several minutes. The site is then at
   `https://soundwithme.onrender.com` (or with a suffix if the name is taken).

Every push to `main` deploys again.

## 3. After the first deploy

1. **Google sign-in:** Google Cloud Console → APIs & Services → Credentials → the OAuth client:
   - Authorized JavaScript origins: `https://<your-app>.onrender.com`
   - Authorized redirect URIs: `https://<your-app>.onrender.com/api/v1/auth/google/callback`
2. **Client addresses** (rate limits must see each visitor's own IP):
   open the service's **Logs** and find the `[forwarded] chain=[…]` lines. The visitor's IP
   should be the entry right before the last `TRUSTED_PROXY_HOPS` entries. If it isn't, change
   `TRUSTED_PROXY_HOPS` in the dashboard. Then delete `LOG_FORWARDED`.
3. Check: sign up by email (the link arrives at your address), join a room, play a song,
   open the site on a phone and try the karaoke mic (HTTPS works out of the box).

## Running the same container locally

```bash
docker build -f infrastructure/docker/app.Dockerfile -t soundwithme-app .
docker run --rm -p 3000:3000 -e PORT=3000 -e WEB_APP_URL=http://localhost:3000 \
  -e MONGODB_URI=mongodb://host.docker.internal:27017/soundwithme \
  -e REDIS_URL=redis://host.docker.internal:6379 \
  -e JWT_ACCESS_SECRET=dev -e JWT_REFRESH_SECRET=dev \
  -e GOOGLE_CLIENT_ID=x -e GOOGLE_CLIENT_SECRET=x soundwithme-app
```
